# AL Studio

A bloat-free, customisable home screen for Android TV boxes, phones and tablets.

## Get the APK

Every push to `main` builds a new APK automatically. Open this repo's **Releases** page and download `AL-Studio.apk` from the newest build. New builds install as updates over old ones.

## Features

- Apps row that opens your real installed apps (YouTube, Netflix, Prime Video, RTÉ Player, Spotify, Twitch, Rooftop Chess), with a Play Store shortcut if one's missing
- Websites row underneath, plus every installed app in **All apps**
- Works with touch and TV remotes (arrows, OK, hold OK for options, Back, Home)
- Loading screen with the app's icon when you open something
- Soft UI sounds (three packs) and your own uploaded sounds
- Custom backgrounds (built-in or your own photo), accent colours, tile style, corners, size, font, clock style and more
- Ad blocker (uses AdGuard's free blocking DNS) with an on/off switch
- VPN using WireGuard files for a few countries (for example from a free Proton VPN account)

## Make it the home screen

Settings → System → **Make AL Studio the home screen**, then pick AL Studio.
